Key Locations on TU Wien Campus and an Image of Bumblebee

A fully responsive web page featuring an HTML and CSS interactive map of TU Wien campus, responsive image, and a mobile-friendly navigation. It adapts from 350 px to Full-HD widescreen.

Bumblebee on Sunflower

The image below shows a bumblebee pollinating a yellow sunflower in summer. Pollinators play a vital role in our ecosystems. The <picture> element below serves a high-resolution file to HiDPI / Retina screens, and the standard version to all other devices.

Extras & Excellence Points

  • CSS-only hover tooltips on the static map: Each marker reveals a label on hover using only CSS — no JavaScript. Uses opacity: 0 transitioning to opacity: 1 on .map-marker:hover .marker-label, with pointer-events: none so the tooltip never blocks the marker.
  • CSS-only hamburger navigation where the icon animates into an X using only checkbox state and CSS transforms. No JavaScript involved at any point.
